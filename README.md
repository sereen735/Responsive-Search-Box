# 🔍 Responsive Search Box

A clean, modern, and interactive **Responsive Search Box** built using **HTML5** and **CSS3**. It features an expandable search input with smooth transition animations, custom heading, a neutral gray background, and a refined footer.

🔗 **Live Preview:**https://resp0nsive-search-box.netlify.app

---

## 🛠️ Built With / Technologies Used

* **HTML5** - Structuring the search container, checkbox toggle mechanism, input field, and page footer.
* **CSS3** - Custom styling, flexbox centering, box shadows, and smooth expansion transition effects.
* **FontAwesome** - Utilizing modern icons for the search interaction.
* **Google Fonts** - Styled using the "Poppins" typography for a professional UI look.

---

## ✨ Key Features

* **Expandable Search Bar:** An interactive search box that smoothly expands upon clicking the search icon using CSS checkbox states.
* **Modern Background & Header:** Designed with a subtle gray background and a clean black heading positioned above the box.
* **Centered Layout:** Uses Flexbox to perfectly center the elements on any screen size.
* **Enhanced Footer:** A clean and professional footer positioned at the bottom of the page.
